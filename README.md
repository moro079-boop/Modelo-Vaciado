# Modelo-Vaciado

Estimación del tiempo de vaciado del acero líquido con las ecuaciones de flujo. Preliminar: ningún parámetro hidráulico está
validado con tiempos de vaciado medidos.

```bash
pip install -r requirements.txt
python vaciado.py
```

Documento del proyecto: [docs/proyecto.md](docs/proyecto.md). Para continuar el trabajo: [docs/siguiente-sesion.md](docs/siguiente-sesion.md).
